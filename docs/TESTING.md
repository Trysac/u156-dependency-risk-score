# Testing\n\n## Coverage\n\nThe `tests/test_dependency_risk_score.py` file contains the test suite covering the core requirements:\n- **Functional Scoring**: Verified against the acceptance specification cases (aging, staleness, maintainers, deprecated, licenses, capped vulnerability scores, sorting logic).\n- **Validation**: Checks `RiskError` raising for `invalid_facts`, `input_too_large`, `invalid_date`, and `invalid_weights` (including rejection of booleans in `Weights`).\n- **CLI**: Tests command-line interface exit codes (0: ok, 1: threshold, 2: errors) and output formats (text/JSON).\n\nAll tests are deterministic, requiring no network or external I/O.
