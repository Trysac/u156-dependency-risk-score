# Security\n\n## Threat Model\n\nThis utility processes untrusted JSON facts files. \n\n### Defended\n- **Denial of Service**: The utility enforces a 5 MiB (5,242,880 bytes) limit on JSON input size and a maximum of 10,000 packages via `load_facts`.\n- **Resource Exhaustion**: Each package is limited to 1,000 vulnerabilities.\n- **Injection/Data Integrity**: Date parsing uses `date.fromisoformat` on strictly validated 10-character `YYYY-MM-DD` strings to prevent complex parsing exploits. Error messages truncate input at 200 characters to prevent log injection.\n\n### Not Defended\n- **Legal Compliance**: This utility calculates risk scores for license categories; it does not audit code or determine legal compliance for commercial or non-commercial usage. The provided license categorization is a project-specific mapping (SPDX ID to category) and not an authoritative legal opinion.\n\n## Limits\n- Input Size: Max 5,242,880 bytes.\n- Package count: Max 10,000.\n- Vulnerability count: Max 1,000 per package.\n- Dates: Strictly `YYYY-MM-DD`.
